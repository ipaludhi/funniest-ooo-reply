The funniest one-line out-of-office reply: the usual "until further notice" turned on itself — further notice is also away. One line, 63 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes one line to `out/entry.txt` (63 characters, no trailing newline):

> I'm away until further notice, and further notice is also away.
